      연결하기

      1. 보드에 MicroPython 펌웨어를 설치합니다.
        Pico: BOOTSEL 누른 채 연결 → .uf2 복사 / micro:bit: python.microbit.org 에서 펌웨어 설치
      2. USB OTG 케이블(C↔Micro-B 등)로 스마트폰과 보드를 연결합니다.
      3. 연결 버튼 → 장치를 선택하면 보드 종류가 자동으로 인식됩니다.

      버튼

      • ▶ 실행: 편집 중인 코드를 저장하지 않고 바로 실행
      • ■ 정지: 실행 중인 프로그램 중단 (Ctrl-C)
      • ⬇ 다운로드: 장치에 main.py 로 저장 후 리셋 → 전원을 다시 켜도 자동 실행
      • ＋ 새로: 연결된 보드에 맞는 라이브러리와 예제로 새 파일 생성

      지원 브라우저

      • Android: Chrome (WebUSB / Web Serial)
      • PC: Chrome, Edge (Web Serial)
      • iPhone/iPad 은 브라우저가 USB 를 지원하지 않아 연결할 수 없습니다 (편집은 가능).
